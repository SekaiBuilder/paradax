# Proyecto: Kana Trainer

Example project for the Media Manager. It records GIFs and reels of a public web app
for learning Japanese. Point `URL de la página` at your own page to record something else;
`proyectos/ACTIVO.txt` says which project file is active.

## URL de la página
https://katrainer.sekaibuilder.com/en/

## Audiencia objetivo
People learning Japanese: students, anime and manga fans, travellers to Japan.

## Identidad
- Theme: Japanese (kanji, minimal design).
- Music: put an instrumental track in `music/` (not included).
- Voices: es-MX-Dalia (Spanish), en-US-Jenny (English), it-IT-Elsa (Italian).
